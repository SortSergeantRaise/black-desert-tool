## 🧩 About

**Black Desert Tool** is a comprehensive overlay utility for Black Desert Online featuring auto-fishing, trade helper, worker manager, node tracker, grind bot, and a customizable menu.

Based on popular tools and community scripts for BDO.

---

## ✨ Features

### 🎮 Core Tools
- Overlay Menu — toggle with a hotkey
- Auto-Fishing — automate fishing and loot
- Trade Helper — calculate best trade routes
- Worker Manager — optimize worker nodes
- Node Tracker — track node investment and resources

### ⚙️ Automation
- Grind Bot — automated grinding for silver and XP
- Auto-Repair — keep gear in top condition
- Auto-Potion — manage HP/MP potions
- Loot Filter — filter and collect valuable drops

### 🗺️ Utility
- Map Overlay — show node and resource locations
- Timer Overlay — track buffs and cooldowns
- Config Profiles — save and load settings
- Process Attach — works with Steam and standalone
